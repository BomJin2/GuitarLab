# 02. UI / UX 상세 디자인 규격

2026-10-20 기능 진단 후속: ‘단음 음정 변화·1초’의 기존 결과 영역에서 주기적 변화 후보가 있으면 속도Hz/깊이cents/관측 반복 수·곡선 적합도와 미확정 주법 안내만 추가합니다. 새로운 디자인/캔버스·차트를 만들지 않고 계산은 native 순수 모듈에 둡니다. 실제 주법 판정·정답/감점처럼 표시하지 않습니다.

> 2026-10-15 사용자 결정: 기능 구현과 안정성을 우선합니다. 이 문서는 현재 기능 배치·상태·접근성·공통 토큰을 위한 참고이며 현재 UI를 완성형으로 간주하지 않습니다. 추후 전체 리디자인을 전제로 최소 UI만 구현하고 불필요한 디자인 작업은 후속으로 남깁니다. UI 교체로 핵심 기능·도메인/IPC·저장 데이터 구조가 바뀌지 않도록 `AGENTS.md`10절과 `docs/03`의 분리 원칙을 따릅니다.

## 디자인 방향

- 목표: Songsterr의 **악보 읽기 편의성**과 현대적인 DAW의 **파형/트랙 컨트롤**, 리듬게임의 **즉시성 있는 판정 피드백** 결합. 다른 서비스의 화면/상표/리소스를 그대로 복제하지 않습니다.
- 분위기: 어두운 차콜 배경, 밝은 악보 캔버스, 낮은 채도의 패널, 판정 상태에서만 강한 컬러.
- UX 핵심: 연주하는 동안 TAB, 현재 프렛, 점수는 가시성이 높아야 하며, 설정/AI 도구는 필요할 때만 보여야 합니다.
- 화면은 **라이브러리**, **곡 작업 화면(카피/연습/연주 전환)**, **연습·연주 결과/녹음 다시 듣기**, **환경 설정** 네 그룹.

## 글로벌 레이아웃 (Windows, 최소 1100×680)

- Window 기본: 1440×900. 콘텐츠 최소 너비 1100, 내부 스크롤/패널 접기 제공.
- 상단 앱 바 56px: 로고/프로젝트명, 저장 상태, 모드 전환 `[카피] [연습] [연주]`, 설정.
- 좌측 탐색 128px(접힌 상태) / 224px(펼친 상태). 카피/연습/연주 모드에서는 기본 접되 숫자 대신 ‘카피·연습·연주’ 등 한글 메뉴명을 항상 표시합니다. 접힌 폭은 공통 토큰 `--spacing-sidebar-compact`로 관리합니다. 초기72px/숫자 표시는 찾기 어렵다는2026-10-20 사용자 요청으로 변경했습니다.
- 하단 transport 88px 고정: 재생/정지, 타임라인, BPM/배속, loop, metronome, master volume.
- 주 콘텐츠는 유연한 패널. splitter 드래그로 크기를 조절하고 프로젝트별로 유지.
- 모든 패널에 loading/empty/error/permission denied/device lost 상태 설계.

## 화면 A. 라이브러리

```text
┌─────────────────────────────────────────────────────────────────┐
│ GuitarLab   내 프로젝트                           [설정]         │
├──────────┬──────────────────────────────────────────────────────┤
│ 라이브러리 │  [ + 새 프로젝트 ] [ 파일 불러오기 ]  검색...         │
│ 최근 연습  │                                                      │
│ 설정      │  프로젝트 카드: 제목 / 커버 대체아이콘 / 마지막 수정   │
│           │  상태: AI 초안 · 확정 · 진행 중 / 최근 점수            │
│           │                                                      │
│           │  빈 상태: '첫 음원을 불러와 시작하세요'                │
└──────────┴──────────────────────────────────────────────────────┘
```

- 새 프로젝트: ① 음원 가져오기 ② 악보도 가져오기/AI 카피/빈 악보 중 선택 ③ 템포/튜닝 ④ 생성.
- 입력 파일은 확장자뿐 아니라 실제 헤더를 검증. 최근 프로젝트 분실 파일은 재연결 UI.

## 화면 B. 카피 모드 (분석·편집 중심)

```text
┌─────────────────────────────────────────────────────────────────┐
│ [←] 곡 제목    ● 저장됨      [카피 ●] [연습] [연주] [내보내기]     │
├─────────────────────────────────────────────────────────────────┤
│ [음원 파형 + 마디/초 타임라인]   ①구간 지정 ②Sync 앵커           │
├──────────────┬──────────────────────────────────┬───────────────┤
│ 트랙 목록    │        TAB / 오선보 에디터        │ 속성 패널      │
│ 기타 1  ●    │ ─────────────────────────────── │ 음 높이       │
│ 기타 2       │ E|-----------------------------| │ 줄/프렛       │
│ 반주         │ B|-------8---------------------| │ 길이/강세     │
│ 원곡         │ G|-----------------------------| │ 운지 후보     │
│              │ ...                             │ AI 신뢰도     │
├──────────────┴──────────────────────────────────┴───────────────┤
│ [AI 분리] [AI 카피] [수동 음표] [Undo] [Redo] [검토 필요만]     │
├─────────────────────────────────────────────────────────────────┤
│ ◀  ▶/❚❚  01:24 / 03:40     ───────●────    0.75×  A-B  ♫     │
└─────────────────────────────────────────────────────────────────┘
```

- 왼쪽 트랙 196~256px, 오른쪽 속성 패널 260~320px, 중앙 나머지.
- 악보 편집: 노트 선택 시 오른쪽에서 줄/프렛/길이 조정, 키보드 입력, 우클릭 추가/삭제. Selection stroke는 청록색.
- AI 검토: 신뢰도 낮은 음표에 점선 테두리 + `검토 필요` 텍스트, 클릭 시 원곡·stem·합성음을 A/B 비교.
- 자동저장: 디바운스 + 저장 중/완료/실패 표시; 실패 시 편집 내용 유지.
- 음원 싱크 앵커: `원곡 시간 ↔ 악보 마디/틱` 쌍을 추가·이동·삭제.

## 화면 C. 연습 모드 (연주 집중)

```text
┌─────────────────────────────────────────────────────────────────┐
│ [←] 곡 제목  [카피] [연습 ●] [연주] 입력: USB Guitar  [캘리브레이션]│
├─────────────────────────────────────────────┬───────────────────┤
│               현재 TAB 악보                 │  SCORE 085,400    │
│   E|--------------------------------------| │  COMBO 128        │
│   B|------8---------7---------------------| │  COOL 98          │
│   G|--------------------------------------| │  GOOD 25          │
│        ▲ 현재 연주 위치                      │  MISS 5           │
├─────────────────────────────────────────────┤                   │
│          가상 기타 지판                      │    COOL!          │
│  e  ─────●──────────────────────────────    │  18ms EARLY       │
│  B  ─────8 [G4]─────────────────────────    │  목표: B줄 8프렛  │
│  G  ────────────────────────────────────    │                   │
├─────────────────────────────────────────────┴───────────────────┤
│ ◀  ▶/❚❚     01:24 / 03:40    0.75×   A-B     카운트인    [종료]│
└─────────────────────────────────────────────────────────────────┘
```

- TAB 최소 화면 전체 가용 공간의 40% 높이를 권장. 현재 마디는 배경 하이라이트, 커서는 선과 작은 글로우.
- 지판은 6줄, 프렛 0~24, 좌우 스크롤/자동 센터링. **악보 목표 운지** 표시라고 명시.
- 판정 텍스트 우측 고정 영역 + 커서 근처 0.5초 임시 애니메이션. 빠르게 입력되면 최근 판정 1개만 중심 표시하고 통계에는 모두 반영.
- 연습 중 편집 기능은 잠금. 편집하기 선택 시 일시정지 후 카피 모드로 이동.
- 목표 음표가 없을 때 지판에 `다음 음을 준비하세요`, 무음 입력일 때는 별도 입력 레벨 경고.
- 재생 전 준비 중에는 작업 화면 중앙에 큰 남은 초(기본3→2→1), 원형 진행 표시와 ‘준비 취소’를 표시합니다. 기존 PlayerEngine의 남은 시간만 사용하고 실제 재생 또는 취소 시 숨깁니다. 마디 카운트인도 같은 표시를 사용하며 동작 줄이기 설정을 존중합니다. 하단 재생/정지 조작을 가리지 않습니다.

## 화면 D. 결과

- 상단: 곡, 모드/속도, 판정 난이도, 총점, 정확도, 최고 콤보.
- 중앙: COOL/GOOD/MISS 비율, 타이밍 분포(EARLY↔LATE), 마디별 성공률 히트맵.
- 하단: 어려웠던 마디 다시 연습, 점수 기록, 동일 조건 재시도.
- 사용자 정의 곡 길이/AI 초안 여부/미지원 음표는 통계 산출에서 구분.

## 화면 E. 설정·오디오 장치

- 입력 장치 선택, 샘플레이트/버퍼 현재값(지원 범위 내), 입력 게인, 노이즈 게이트, 입력 레벨 meter.
- 볼륨 낮음/클리핑/장치 사라짐 상태 배지 대신 **텍스트+아이콘**을 표시.
- calibration wizard: 장치 확인 → 입력 레벨 검사 → 리듬 박자 맞춰 치기 → 반복 측정 → 보정값 확인/수동 조절 → 저장.
- AI 모델 관리: 모델별 용량/설치/삭제/라이선스 정보, GPU/CPU 옵션.
- 저장 공간: 프로젝트 위치, 모델/캐시/파생 파일 용량, 안전한 캐시 정리.

## 타이포·간격·크기

- UI: `Pretendard`(설치/라이선스 확인 필요) 또는 OS 시스템 폰트 fallback. 악보는 alphaTab의 음표 폰트/엔진 사용.
- 크기: 화면 제목 24/32, 섹션 18/26, 본문 14/22, 서브 12/18, 스코어 수치 32/40, COOL 텍스트 28/36.
- spacing 4px 기준: 4,8,12,16,24,32. panel padding 16~24.
- 버튼: 36~40px 높이, 주요 재생 버튼 48px, 최소 타깃 36×36px.
- Radius: 작은 컨트롤 8px, 패널 12px, 카드 14px.
- Motion: COOL 150~280ms scale+fade, GOOD 150ms, MISS 180ms shake **과하지 않게**. '동작 줄이기' 시스템 설정 지원.

## 반응과 상태 규칙

- 실행 중 AI 작업은 모달이 아닌 가능한 한 background 작업 패널(앱 내부)을 보여주고 취소 제공. 사용자에게 앱을 닫아야 한다는 식으로 설계하지 않음.
- 재생 중 토스트가 TAB 위에 겹치지 않도록 우상단에 표시.
- 키보드 포커스가 텍스트 입력 중이면 Space 등 글로벌 단축키 비활성화.
- 입력 장치 끊김: 채점 일시정지 + '장치가 연결 해제되었습니다' + 재연결 버튼. MISS로 억지 계산하지 않음.
- Phase 4 저장 UI: 라이브러리의 제목·선택 아티스트·모드 폼과 실제 프로젝트 목록, 작업 공간의 프로젝트/저장 버전·변경 여부와 저장 버튼. 파일 선택 시 관리용 복사(기본)/외부 참조를 구분하고 진행·취소·누락 원본 재연결을 제공합니다. 임의 파일 경로 입력란을 만들지 않습니다.
- Phase 4 결과: 실제 저장 시도 선택, 판정 분포·타이밍 히스토그램·마디별 정확도와 비교 가능한 최고 기록. 감점 제외는 분모에서 빼고 INTERRUPTED/INVALIDATED와 정상 완료를 구분합니다. 데이터 없음/손상/저장 실패는 빈 상태·명확한 오류로 표시합니다. 아직 저장하지 않은 악보의 연습은 메모리 기록임을 안내합니다.
- AI 신뢰도 낮음: 사용자에게 '초안/수정 필요' 안내, 실제 정확도를 확정하는 표현 금지.
