## 목표

사용자 음원으로부터 **편집 가능한 TAB 초안**을 만드는 배치 파이프라인입니다. 사용자가 직접 TAB를 작성하는 경로와 충돌하지 않습니다. 원곡/중간 결과/확정 악보는 서로 분리하여 저장합니다.

## 전체 파이프라인

```text
오디오 업로드(import)
  → 유효성 검사 및 안전한 디코딩
  → stem separation (guitar / accompaniment, 모델 지원 시)
  → stem preview + 수동 선택/재시도
  → transcription (Basic Pitch / 교체 모델)
  → notes {onsetMs, offsetMs, pitchMidi, confidence, bend?}
  → beat/tempo/onset alignment (librosa 등; 자동 결과는 수정 가능)
  → 정량화 / 겹치는 음표 정리 / 불확실 구간 플래그
  → 튜닝·프렛 제한에 따른 가능한 줄/프렛 후보 추정
  → ScoreDocument 트랙으로 import(상태: AI_DRAFT)
  → 사용자가 waveform/노트 듣고 검토·수정 → 확정(PUBLISHED_LOCAL)
```

## 모듈과 어댑터

- `decoder`: 확장자·MIME/실제 포맷·파일 크기/길이·채널수·샘플레이트 검증.
- `separator`: 교체 가능한 분리 어댑터, 설치 모델 목록 및 모델별 stems 명세 제공. `audio-separator`는 초기 후보였으며 아래 라이선스 검토에 따라 실제 채택을 별도로 결정합니다. 선택한 모델이 기타 스템을 지원하지 않으면 '기타 분리 불가' 안내.
- `transcriber`: `Basic Pitch` 기본 후보. 한 악기 녹음에서 유리하며 polyphonic 결과는 후처리 필요.
- `aligner`: 원곡 waveform과 MIDI events 시간축 조정. 고정 BPM 가정 금지. 수동 sync anchor 보정 UI 함께 제공.
- `quantizer`: 음표 길이를 음악적 단위로 근사하되 swing/셋잇단음/당김음 및 rubato를 훼손하지 않게 옵션 제공.
- `fingering`: pitchMidi만으로 가능한 현/프렛을 후보로 생성. 문맥/손 위치 이동 비용으로 순위 매기되 '정답'으로 확정하지 않음.
- `export`: JSON NoteEvents + confidence + 모델 버전/설정 + 소스 링크. 단계별 미리듣기 결과 파일.

## 단계별 UI 제약

1. 분리 대상: `기타 트랙`, `기타 제외 반주` 모델 지원 확인 후 선택.
2. 분석 옵션: 초급/표준/고품질, CPU/GPU, 곡 일부만 분석할 구간.
3. 진행 상태: 검증(0-5%) / 분리(5-45%) / 음표 분석(45-80%) / 운지 생성(80-95%) / 저장(95-100%). 퍼센트는 작업 완료 근거가 있는 진행만 사용하며 임의 시간 약속 금지.
4. 완료 후 초안: 노트별 confidence, 운지 모호성, 소리 비교, 수동 수정 권고.
5. 실패/취소: 안전하게 임시 파일 정리, 이전 사용자의 편집물 불변.

## 입력과 결과

- 입력: 프로젝트 관리 위치의 합법적으로 소유/이용 허가 받은 로컬 파일. 외부 URL 임의 다운로드 없음.
- 권장 내부 오디오: 분석 adapter별 요구 스펙으로 리샘플링; 사용자 원본은 그대로 보존.
- 음표 결과: `onsetMs`와 `offsetMs` 모두 원곡 시간축 또는 stem 시작 오프셋을 명시. 분석 시작 오프셋이 결과에 정확히 반영되어야 함.
- `confidence`는 모델 신뢰도 추정치이지 실제 정답 확률 보증이 아님.
- 에러: model missing, out-of-memory, unsupported format, transcription empty, canceled, invalid output.

## 운지 할당 예시

- 표준 튜닝 G4 (MIDI 67): 1번 줄 3프렛(E4+3), 2번 줄 8프렛(B3+8), 3번 줄 12프렛(G3+12) 등 후보.
- 단일 음만으로 줄 선택 불가능. 연속 노트 시 포지션 변경 최소화 + 피킹/현 이동 비용 + 프렛 한도 제약으로 탐색.
- 기타가 아닌 베이스 또는 피치가 연주 가능 범위 밖이면 변환 실패를 알려야 하며 임의 음정 왜곡 금지.

## 위험과 대안

- 원곡 여러 악기 혼합: stem bleed로 노트 검출 악화 → stems 원음 A/B 비교, 분리 모델 교체.
- distorted chord/리버브: 음표 누락/중복 → confidence 기반 검토, threshold 설정.
- polyphony: 복잡 코드와 동시음 검출 한계 → chords를 '검토 필요' 표시, 학습용 자동 정답으로 즉시 채점 금지.
- 템포 변경/인트로: 악보와 맞지 않는 구간 → 수동/반자동 sync anchor 지원.
- GPU·장치 사양 편차: CPU 모드/짧은 구간 우선 분석 옵션 제공.
- 모델/가중치 라이선스: 프로젝트 코드 라이선스뿐 아니라 다운로드한 **개별 모델 가중치 이용조건** 확인.

## Python IPC 규칙

- stdin으로 JSONL 명령을 받고 stdout으로 JSONL 이벤트를 한 줄에 하나씩 보냅니다. 각 메시지에 `protocolVersion`, `jobId` 포함.
- stdout에 `print('hello')`, tqdm progress bar 또는 라이브러리 로그를 섞지 않습니다. stderr는 진단 로그.
- 취소: Sidecar에 cancel 메시지 또는 프로세스 정상 종료 요청, timeout 후 안전 종료 정책; job별 임시 디렉터리.
- 상호호환 계약은 `docs/12-API-CONTRACTS.md`를 참조합니다.

## Phase 6 개발 구현 범위 — 2026-10-17

사용자가 승인한 별도 Basic Pitch0.4.0/ONNX CPU 환경에서 전체 로컬 WAV를 분석합니다. 이 Basic Pitch 명령은 분리 미리보기와 독립적이므로 다른 악기의 음도 포함될 수 있습니다. 원본과 같은 프로젝트의 ORIGINAL asset만 읽고 새 작업 사본에서 처리하며 원본/기존 악보/테이크는 바꾸지 않습니다. 지원 입력은60초/64MiB 이하 PCM16·float32 mono/stereo WAV입니다. 모델 파일의 고정 SHA-256과41개 패키지 버전 검증 전에는 로드하지 않습니다. ONNX telemetry는 비활성화합니다.

수동 싱크 앵커와 선택 트랙 튜닝으로 정량화/권장 운지를 계산한 AI_DRAFT를 카피 화면의 별도 TAB와 표에 표시합니다. confidence는 평균 note activation이며 정답 확률이 아닙니다. 낮은 활성도·음역 밖·여러 운지·박자 이동·화음/중첩을 표시하고 화음/음역 밖 운지는 보류합니다. TAB renderer의 지원 범위를 벗어나면 표와 이유만 표시합니다.

## 전체 기타 분리 사전 검토 — 2026-10-17

Demucs4.1.0/CPU Torch2.8.0+cpu/HTDemucs-6s의 별도 Python3.10 Windows 개발 환경을 계획했습니다. `audio-separator`0.30.2의 Windows 필수 diffq-fixed 비상업 조건을 피하지만, Demucs 가중치 자체의 연구 용도 안내는 별도 제약입니다. 상용 제품 모델로 선정하지 않았고 다운로드·설치·분리 실행은 미실행입니다. 자세한 근거/목록은 `00`·`10`과 `../ai/models/README.md`를 따릅니다.

후보가 지원하는 guitar는 **전체 기타**입니다. Lead/Rhythm 분리를 지원한다고 표시하지 않습니다. 구현 시에는 SHA-256 검증한 로컬 safetensors와 허용된 HTDemucs 클래스만 로드하고 자동 네트워크/legacy pickle 폴백을 허용하지 않습니다. 기존 악보/테이크와 별도 파생 stem을 저장하고 원본 길이·채널·유한 샘플·시작 오프셋을 검증하는 계약을 구현 전에 추가해야 합니다. 이 문단은 구현 완료 설명이 아닙니다.

### 사용자 승인 후 Demucs 개발 연결 — 2026-10-17

위 사전 검토 후 사용자가 Demucs 사용을 요청해 별도 `.venv-demucs`를 설치했습니다. 고정31개 wheel/2개 모델 파일의 크기·SHA-256을 확인하고 offline pip 설치/check 및 실제 자체4초 분리를 통과했습니다. 연구용 가중치 안내와 재배포 보류는 유지합니다. 위 사전 검토의 미설치/미실행은 당시 이력입니다.
