# 01. 제품 기능 명세 (PRD)

## 핵심 사용자 스토리

- 사용자는 로컬 음악 파일과 GP/MusicXML 악보를 불러와 재생하면서 현재 TAB 음표를 볼 수 있습니다.
- 사용자는 원곡을 듣고 직접 TAB를 작성하거나 AI 자동 카피 초안을 생성해 수정할 수 있습니다.
- 사용자는 기타(마이크/오디오 인터페이스)를 연결해 목표 음정과 연주 시점을 기준으로 판정받고 실수를 확인할 수 있습니다.
- 사용자는 속도를 낮추고 A-B 구간 반복·카운트인 후 재시도하며 최고 기록과 취약 마디를 확인합니다.

## 기능 ID / 우선순위 / 수용 조건

### F-01 라이브러리·프로젝트 [MVP]

- 파일 선택/드래그 앤 드롭으로 MP3, WAV, FLAC, OGG(디코더 호환성 확인), GP3/4/5/GPX/GP, MusicXML을 읽습니다. 확장자는 실제 지원 확인 후 UI에서 노출합니다.
- 프로젝트는 제목·아티스트(선택)·원본 파일 링크/관리용 복사·마지막 재생 위치·악보·보정값을 갖습니다.
- 잘못된 파일/손상/권한 거부 시 명확한 오류 + 원본 보존.
- AC: 재실행해도 로컬 프로젝트 목록과 악보/설정 복구, 중복 import 안내.

### F-02 악보 플레이어 [MVP]

- TAB 전용 / TAB+오선보 보기 전환, 트랙 선택, 악보 확대/축소, 세로/가로 보기.
- 음원 타임라인을 중심으로 재생/일시정지/seek 시 현재 마디·음표 하이라이트.
- AC: 재생/seek/정지/loop 시 커서와 표시 음표가 정확한 시간 매핑을 따름.

### F-03 연습 컨트롤 [MVP]

- 속도: 0.5×~1.5× (기본 1.0, 세부 범위는 플레이어 엔진 검증에 따라 조정). 가급적 피치 보존.
- A-B 루프: 마디/타임라인에 시작·끝 지정, 해제, 최소 길이 제한.
- 카운트인: OFF / 1마디 / 2마디. 메트로놈 on/off 및 음량.
- 트랙 믹싱: 원곡/기타 stem/반주/메트로놈에 개별 볼륨과 뮤트.
- AC: 루프/seek/속도 변경 후 판정 이벤트가 중복 집계되지 않음.

### F-04 입력 및 튜너 [MVP]

- 입력 장치 열거, 기본 장치 자동 선택, 오디오 인터페이스/마이크 사용, 입력 gain/모니터링 상태, 튜너.
- 캘리브레이션: 타이밍 오프셋(ms)과 소음 게이트/감도 조정, 장치별 프로필 저장.
- AC: 장치 미연결·변경/마이크 권한 문제를 사용자에게 안내하고 복구 가능.

### F-05 실시간 리듬게임 판정 [MVP 단음부터]

- 예상 음표에 연주 음정(onset와 MIDI pitch)을 1:1 매칭하고 COOL/GOOD/MISS 판정.
- EARLY/LATE를 ms 단위, WRONG NOTE 별도 기록. 판정 설정(Easy/Normal/Hard).
- 스코어·콤보·최고 콤보·정확도·곡/구간 결과와 히스토리.
- AC: 동일 입력 fixture의 판정이 매번 동일하며, seek/중지/루프 시 점수 누적 정책 일관.

### F-06 수동 악보 편집 [정식 1차]

- 악보를 새로 생성하거나 불러온 악보에서 음표 추가/삭제/이동, 박자·길이·줄/프렛, 트랙·튜닝 설정.
- Undo/Redo, 자동 저장, 이전 버전/원본 악보 보관, MusicXML 또는 GP 호환 가능한 범위 내 내보내기.
- AC: 음표 수정 후 피치(튜닝+프렛)와 악보 디스플레이가 동기화. Undo로 원상 복귀.

### F-07 AI 기타 분리 [정식 1차]

- stem 분리 모델이 지원하는 경우 guitar / accompaniment(기타 제외)를 생성.
- 성능·모델 용량·설치 여부·진행률/취소/오류 안내. 음원 길이·PC 사양별 처리 차이 반영.
- AC: 선택한 stem 파일을 재생할 수 있고 오리지널 원본이 보존됨.

### F-08 AI 카피 및 교정 [정식 1차]

- 추출된 기타 stem 또는 깨끗한 솔로 기타 녹음→음표(MIDI pitch, onset, offset, confidence) 추정.
- 박자 정량화 및 튜닝/기타 음역을 고려한 줄·프렛 운지 후보 자동 작성.
- 미확신 부분 하이라이트, 원음 대비 미리듣기, 악보 수정/운지 재배치.
- AC: 자동 악보는 'AI 초안' 상태로 저장되며 사용자가 확정한 뒤 연습 목표로 전환.

### F-09 고급 채점 [고급]

- 동시 음정 화음 매칭, sustain/뮤트, 벤딩 pitch contour, 슬라이드/해머링 등 주법 분석.
- 지원 불가 또는 낮은 신뢰도는 부정확한 감점을 하지 않고 '판정 보류/미지원'으로 표시.
- AC: 다성·주법 테스트 세트에 대한 오탐/미탐을 측정하고 일반 판정과 분리 가능.

### F-10 연습 리포트 [정식 1차]

- 판정 분포, 타이밍 오차 히스토그램, 마디별 정확도, 최고 기록, 직전 기록 대비 개선점.
- AC: 동점 최고 기록 처리 규칙 명확, 데이터가 없으면 빈 상태 UI.

## 일반 요구사항

- 한국어 우선, UI string 리소스 분리(향후 영문 지원).
- 키보드 지원: Space 재생/정지, 좌/우 탐색, R 반복 토글, Esc 모달 닫기. 입력 중 단축키 오작동 방지.
- 스케일: 기본 1280×800 권장, 최소 1100×680(하단 패널 스크롤/접기), 고해상도 DPI 대응.
- 다크 모드 우선, 라이트 모드 확장; 색에만 의존하지 않는 판정 텍스트.
- 데이터 저장/복구, 크래시 복구, 실패 시 원본 보호.

## 이번 프로젝트에서 제외 (추후 별도 기획)

- 온라인 곡/악보 불법 공유, 타인의 저작물 무단 호스팅.
- 실시간 멀티플레이/랭킹 서버, 계정 시스템, 클라우드 동기화.
- 정확한 물리적 프렛 위치 확인을 위한 특수 MIDI/센서 기타 하드웨어 통합.

## 정의된 완료 기준

각 기능은 **화면 구현 + 실제 기능 연결 + 오류/빈 상태 + 테스트 + 문서 업데이트**까지 통과해야 Done으로 간주합니다. 컴포넌트 껍데기·플레이스홀더·임의 숫자 표시만 구현한 기능은 Done이 아닙니다.

## v0.2 신규 기능 명세 (F-11 ~ F-15)

### F-11 연주 모드 [정식 1차]

- 카피/연습/연주 3모드, 악보 다중 기타 트랙 중 목표 트랙 선택, 트랙별 판정/점수 및 반주 소스 연결.
- 악보 트랙 / 오디오 stem / 녹음 take를 명확히 구분하고 독립적으로 제어.
- **AC**: Lead 악보와 Rhythm 악보 선택 시 표시·판정 대상만 바뀜. 데이터 누수/중복 판정이 없음. `docs/15`.

### F-12 연주 녹음·리플레이 [정식 1차]

- `REC` opt-in 사용자 입력 녹음, WAV, 테이크 목록, 부분 재생, A/B 비교, 판정 히스토리/악보 타임라인.
- **AC**: 명시적 녹음이 없으면 파일 생성 안 됨. 재실행 후 재생 가능, crash recoverable, 반주/YouTube가 기록되지 않음. `docs/17`.

### F-13 오버더빙/멀티트랙 믹싱 [정식 1차 이후]

- 이전 lead take를 재생하면서 rhythm take를 별도 녹음, 볼륨/mute/solo/offset 조정, 로컬 반주 + 개인 take의 WAV export.
- **AC**: 기존 take 변형 없이 2개 이상 녹음 레이어 저장·복구·solo·export 성공. YouTube 오디오 미포함.

### F-14 Backing Track Finder [온라인 선택 기능]

- 악보 정보로 backing track 검색, YouTube 정식 player로 재생하거나 로컬 반주 선택. 검색 결과에서 기타 없는 여부는 사용자 확인.
- **AC**: 인터넷/검색 키/임베드 실패 시 로컬 폴백. YouTube 오디오 캡처·다운로드 없음. 정밀 판정 동기화 미확인 시 채점 제한. `docs/14`.

### F-15 리드·리듬 기타 분리 [악보 기본/음원 AI 실험]

- GP/MusicXML에서 개별 guitar score track 표시, 사용자가 가진 stem 파일 파트별 라우팅.
- Local song 기타 전체 제거는 모델 지원 시, lead/rhythm 음원 AI 2-way split은 품질 평가 통과한 모델로만 실험/사용자 승인.
- **AC**: 일반 stem 모델로 `리드만 제거 가능`이라는 잘못된 상태를 표시하지 않음. AI 결과는 검토·수동 역할 수정 가능. `docs/16`.
