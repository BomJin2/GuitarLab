# 남은 작업과 완료 기준

기준일2026-10-24. 기본 범위 수용 완료는14개 단계 중9개(0~5,2A,4A,4B)입니다. 이 수치는 단계 개수이며 전체 공수나 품질의 완료율이 아닙니다. 남은5개 단계의 일부 기능도 구현돼 있지만 아래 조건을 충족하기 전 전체 완료로 표시하지 않습니다.

| 단계 | 이미 확인한 범위 | 남은 핵심 작업/조건 |
|---|---|---|
| 6 AI 카피/분리 | Basic Pitch/Demucs 로컬 설치·실제 자체 분석·초안/분리 보존·Python3.12 독립 실행, GitHub Server의 모델 없는 기본 runtime 설치 | 지원 개발 도구가 없는 별도 Windows10/11의 DLL/WebView2·모델 첫 설치/오프라인 조건 확인. 현재 사용자에게 별도 PC/VM이 없음 |
| 6A YouTube | URL 직접 입력·공식 플레이어·영상/TAB 수동 맞춤 보존 | 앱 내부 API 검색은 사용자가 URL 입력 방식을 선택해 보류. 현재 기본 경로를 막는 항목이 아님 |
| 6B 기타 파트 | 사용자 제공 리드/리듬 파일·믹스·녹음/재생 | 검증된 특화 모델의 가중치 이용 조건/실제 두 기타 분리 품질. 현재 Demucs는 전체 기타만 추정 |
| 7 고급 판정 | 실험적 다중 음정/단음 변화 진단·공개 자료의 고정 평가 | 코드/제한된 주법별 검출·실제 정답 자료·허위 감점률/지연 수용. 고급 실시간 점수는 비활성 |

기본 연습/녹음/편집 앱은 사용할 수 있으나 남은 고급 인식·분리와 출시 검증은 작은 UI 수정과 성격/난도가 다릅니다. 정확한 종료 날짜는 아직 산정할 수 없으며, 실제 품질 평가와 외부 환경 수용 결과를 기준으로 작업량을 다시 판단합니다. UI 전면 리디자인은 현재 기능 우선 개발의 별도 후속입니다.

공개 기타 자료의 분석 창 문맥/신호 대조를 완료했고 실제 성부/잔향/주석 오류 원인은 미확정입니다. 현재 PC의 최신 release 격리 설치/Defender와 새 Git checkout의 LF 재현성·GitHub Server 설치/정상 종료/제거·전체 회귀도 통과했습니다. 고정 공개8파일/281타격의 실제 기준선도 측정했습니다(337검출/±50ms 대응281/추가56). 원문 음정 None8개·범위 밖76개로 음정 참조 해석은 보류하며 범위 안197개도 정답으로 확정하지 않습니다. 추가56개는 후보1/미확정55이며 대응281개에도 미확정39개가 있어 실제 채점 성능으로 확대하지 않습니다. 별도 음정 주석/README는 시간 초과2회 뒤 세 번째223635바이트 수신으로 확보했습니다.273행 원문/CSV가 일치하지만 단위 문제는 원문에도 남아 있습니다. 팜뮤트3파일의 선언 MIDI 가정159개에서는 음정 관측132/없음27·선언값보다 약1옥타브 높은4곳이 있어 실제4096프레임 검출 창/조건을 재현했고 잔차 비율0.4 가설은 다른 GuitarSet 단음 대조군에서 기존 적중10개 퇴행/개선0으로 기각했습니다. 다음은 임계값 숫자 재조정이 아니라 신호 문맥/기본음 증거와 독립적인 실제 참조를 확인하는 연구입니다. 이는 정답 수용/실제 정확도 측정이 아니며 새 모델/개인 녹음·고급 채점 활성화는 하지 않습니다. 최신 코드/CI/실행 앱은 [진행 상태](README.md), 분석 한계는 [Phase7](PHASE-07.md), 설치 증거는 [Phase8](PHASE-08.md)을 확인합니다.
