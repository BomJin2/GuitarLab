에이전트(Claude)가 자동으로 확인할 수 없는 항목만 모았습니다. 시간 날 때 한 번에 확인하고 결과를 알려 주세요.

자동으로 확인한 항목은 `PHASE-08.md`의 "에이전트 앱 확인"에 기록합니다. 이 목록에는 넣지 않습니다.

- **확인 방법**: 검증앱을 실행한 뒤 각 항목을 해 보고, 줄 끝의 `[ ]`에 결과를 적어 주세요(예: `[OK]`, `[문제: …]`).
- **최종 갱신**: 2026-11-05

## 소리·녹음(실제 기타·귀가 필요)

1. **새 녹음 자동 믹스** `[ ]`
   - 연주 화면에서 기타 입력을 켜고, 입력 미터가 움직이는지 먼저 확인합니다.
   - REC로 짧게 녹음하고 STOP합니다.
   - 확인: 아래 "로컬 믹스 · 오버더빙"과 하단 믹서에 새 테이크 줄이 자동으로 생기는지, 잠시 뒤 "믹스 준비 완료"가 뜨는지.
2. **반주와 새 테이크 같이 듣기** `[ ]`
   - 1번 다음에 재생바로 재생합니다.
   - 확인: 반주(로컬 반주 음소거를 끈 상태)와 방금 녹음한 소리가 같이 들리는지, 박자가 크게 어긋나지 않는지.
3. **하단 믹서로 소리 조절** `[ ]`
   - 재생 중에 하단 믹서에서 테이크의 M(음소거), S(Solo), 음량을 바꿔 봅니다.
   - 확인: 들리는 소리가 바로 바뀌는지.
4. **DAW에서 새 테이크 파형** `[ ]`
   - 1번 테이크를 DAW 보기에서 봅니다.
   - 확인: 파형 높이가 실제로 연주한 세기와 비슷해 보이는지, 소리 나는 위치와 파형 위치가 맞는지.

7. **왼쪽 트랙 목록 접기** `[ ]`
   - 카피·연습·연주 화면 왼쪽 위의 "◂ 트랙 목록 접기"를 눌러 봅니다.
   - 확인: 접었을 때 악보가 넓어져 보기 편한지, ▸ 버튼이 찾기 쉬운지.
10. **하단 믹서 레벨 막대·클리핑 경고(실시간 포함)** `[ ]`
    - 연습·연주 화면 하단 믹서에서 각 줄 음량 옆의 작은 막대와, 마스터 줄의 막대·숫자를 봅니다.
    - 반주 음소거를 끄고 음량을 크게 올려 합계가 1을 넘게 만들어 봅니다.
    - 재생하면서 마스터 줄의 "실시간" 숫자와 막대가 소리 크기에 맞춰 움직이는지 봅니다.
    - 확인: "클리핑 가능 · 최대 합계 추정 …" 경고가 뜨는지, 실제로 소리가 커질 때 "실시간 클리핑 발생"이 뜨는지, 막대가 보기 불편하지 않은지. 실제로 소리가 찢어지는지 귀로 들어 보면 더 좋습니다(경고는 상한 추정이라 실제로는 깨끗할 수도 있습니다).
11. **X로 앱 닫기(오래 켜 둔 뒤)** `[ ]` (짧게 쓴 뒤 닫기는 2026-11-05 사용자 확인 OK)
    - 앱을 켜 둔 채 다른 작업을 오래(30분 이상) 한 뒤 돌아와 창의 X를 눌러 봅니다. 원인(숨은 창 파괴)을 막는 수정이 들어갔습니다.
    - 확인: 바로 닫히는지. 안 닫히면 화면에 뜬 문구와 그 전에 한 조작을 알려 주세요. 누가 숨은 창에 닫기 메시지를 보내는지는 아직 모릅니다.
12. **스윙 곡 연습 채점** `[ ]`
    - 스윙(셋잇단 느낌) 표기가 있는 GP 악보로 연습 채점을 해 봅니다.
    - 확인: 8분음표 뒤 음을 스윙으로 치면 COOL/GOOD이 나오고, 곧게(정박 반) 치면 늦거나 이르게 판정되는지.
13. **주법 편집과 팜뮤트·스타카토 채점** `[ ]`
    - 카피 화면 편집 패널에서 음을 고르고 "주법"의 팜뮤트·벤딩 등을 체크해 적용합니다. 악보에 P.M.·물결·T 등이 보이는지 확인합니다.
    - 팜뮤트·스타카토 음이 있는 악보로 연습 채점을 해 봅니다.
    - 확인: 팜뮤트를 제대로 쳤는데 MISS가 자주 나지 않는지(소리가 짧고 탁해 음정 검출이 어려울 수 있음). 다른 프로그램에서 만든 GP의 주법이 편집 가능하게 열리는지.
14. **주법 v2(해머온·슬라이드·하모닉·렛링)와 GP7 내보내기** `[ ]`
    - 카피 편집 패널에서 해머온·슬라이드 등을 체크해 적용한 뒤 "새 GP7로 내보내기"로 저장합니다.
    - 확인: 저장한 .gp를 Guitar Pro·TuxGuitar 등에서 열면 주법이 보이는지. 해머온을 연주하면 도착 음 때문에 MISS가 나지 않는지.
    - MuseScore 등에서 해머온·풀오프·하모닉이 든 악보를 MusicXML(.musicxml 또는 압축 .mxl)로 내보내 불러옵니다. 확인: 악보에 H 표시가 나오고 편집 칸에 해머온이 체크돼 있는지.
    - 오선보+TAB 두 보표 악보는 연습 채점에서 같은 음이 두 번 기다리지 않는지(한 번 치면 COOL/GOOD 하나)도 확인합니다.
