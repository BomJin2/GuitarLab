# 21. 처음 사용하는 분을 위한 빠른 시작

기준일: 2026-10-26. 현재 개발 빌드의 버튼과 기본값을 기준으로 작성했습니다. 화면 디자인은 추후 바뀔 예정입니다. 설치/개발 실행은 [환경 안내](13-ENV-AND-RELEASE.md), 실제 검증 범위는 [진행 상태](progress/README.md)를 확인하세요.

## 먼저 알아둘 세 가지

편집 단축키 후속 빌드에서는 카피의 **수동 음표 편집** 패널에서 **Ctrl+Z**로 되돌리고 **Ctrl+Y** 또는 **Ctrl+Shift+Z**로 다시 실행합니다. 프렛 등 입력칸에 초점이 있으면 입력 내용 자체의 되돌리기를 유지합니다. 별도 TAB 영역/앱 전역 단축키는 아니며 편집 시작·녹음/파일 작업 잠금을 따릅니다. 실제 적용/미실행 범위는 [Phase5 기록](progress/PHASE-05.md)을 확인하세요.

| 용어 | 뜻 |
|---|---|
| 프로젝트 | 한 곡의 악보·반주·녹음·설정을 묶어 보관하는 단위 |
| 테이크 | REC를 눌러 한 번 녹음한 기타 파일 |
| 모니터 | 지금 치는 기타 소리를 헤드폰/스피커로 듣는 기능 |

**입력 시작, 모니터, REC는 서로 다릅니다.** 입력을 시작하면 튜너가 움직이고, 모니터를 켜면 내 소리가 들립니다. 파일은 REC를 눌렀을 때만 만들어집니다. 모니터를 꺼도 이미 시작한 녹음은 계속됩니다.

## 1. 기타 입력부터 확인하기

1. 기타를 오디오 인터페이스에 연결합니다. SSL 2 MKII의 물리적1번에 꽂았다면 앱에서도 이름에 **Input 1**이 있는 장치를 고릅니다.
2. 왼쪽 **환경 설정**으로 갑니다. 입력 장치 목록은 자동으로 불러옵니다. 장치를 새로 연결했거나 목록이 오래된 경우에만 **입력 장치 새로고침**을 누릅니다.
3. **입력 장치**와 **입력 채널**을 확인하고 **선택 장치 입력 시작**을 누릅니다. 장치 이름의 Input 1/2와 그 장치 안의 채널 번호를 혼동하지 마세요.
4. 아무 줄이나 한 번 튕겨 튜너의 음 이름과 Hz가 움직이는지 확인합니다. 튜너는 실제 줄 번호나 프렛을 알아내는 기능이 아닙니다.

입력 설정 유지 후속 빌드에서는 화면을 옮겼다가 입력을 중단해도 마지막 실제 장치·채널·게이트가 남습니다. 다시 입력하려면 **선택 장치 입력 시작**을 누르세요. 장치가 사라졌거나 채널 수가 바뀌었다는 안내가 있으면 장치/채널을 다시 선택해야 합니다. 앱을 새로 켠 뒤 선택까지 저장하는 기능은 아닙니다.

### 튜너는 움직이는데 내 소리가 안 들릴 때

모니터는 **기본 꺼짐**입니다. **내 기타 듣기**에서 출력 장치를 확인하고 **🎧 모니터 켜기**를 누릅니다. 처음에는 PC 기본 출력이 선택되므로, SSL에 연결한 헤드폰으로 들으려면 SSL 출력 장치인지 확인하세요. 음량은 낮게 시작해 올립니다.

SSL의 하드웨어 MIX를 USB 쪽으로 두면 앱에서 돌아오는 소리를 들을 수 있습니다. INPUT 쪽의 직접 듣기와 앱 모니터를 동시에 사용하면 소리가 겹쳐 들릴 수 있습니다. **🎧 모니터 끄기**는 듣기만 끄며 녹음 파일의 음량을 바꾸지 않습니다.

## 2. 연습할 프로젝트 준비하기

1. **라이브러리**에서 제목을 입력하고 **새 프로젝트 만들기**를 누릅니다.
2. **프로젝트 악보 선택**으로 가지고 있는 Guitar Pro/MusicXML 또는 GuitarLab JSON을 엽니다. 처음에는 기본 **관리용 복사**를 사용하면 프로젝트가 원본의 복사본을 관리합니다.
3. 악보가 없다면 **빈 악보 만들기** → **카피** → **안내 확인 · 편집 시작**에서 줄·프렛을 정해 **새 음표 적용**으로 작성할 수 있습니다.
4. 반주가 있다면 **프로젝트 음원 선택**으로 로컬 WAV를 엽니다.
5. **프로젝트 저장**을 누릅니다. **악보 저장됨**을 확인하세요. **프로젝트 다시 열기**는 마지막 저장본을 다시 읽는 동작이므로 미저장 편집 안내가 나오면 내용을 확인합니다.

기본 악보는 TAB입니다. **오선보 보기**를 눌러 음표 표기로 전환하고 **TAB 보기**로 돌아올 수 있습니다. 기본 편집은 단성 악보 중심이며 복잡한 주법 표기를 모두 편집할 수 있는 것은 아닙니다.

### 저장한 프로젝트 찾기·이름 바꾸기

2026-10-26 후속 빌드의 기능입니다. 라이브러리의 **프로젝트 검색**에 제목이나 아티스트를 입력하면 이미 읽은 로컬 목록에서 찾습니다. 여러 단어를 입력하면 모두 포함한 항목을 표시하고 **검색 지우기**로 전체 목록으로 돌아갑니다.

프로젝트를 연 다음 라이브러리의 **수정할 프로젝트 제목 / 아티스트**를 입력하고 **프로젝트 정보 저장**을 누릅니다. 제목은 필수, 아티스트는 비워둘 수 있고 각각200자까지입니다. 이 작업은 라이브러리의 이름을 수정하며 악보 내부 제목·원본 파일명은 그대로 유지합니다.

### 예전에 저장한 악보 내용 확인하기

같은 후속 빌드에서 열린 프로젝트의 저장 영역에 **저장 악보 버전 보기** → **최신 버전 목록 읽기**를 누릅니다. **저장 버전**을 고른 다음 **저장 내용 조회**를 누르면 당시 제목·트랙·음표 표를 볼 수 있습니다.100개보다 많은 저장 이력은 **이전 버전 목록**으로 넘깁니다. 현재 편집 중인 악보와 재생 위치는 그대로이며, 이전 버전을 적용하거나 복원하는 기능은 아직 없습니다.

새 후속에서는 조회한 저장 편집본의 **조회 버전을 새 JSON으로 내보내기** 또는 **새 MusicXML로 내보내기**로 별도 파일을 보존할 수 있습니다. ‘출력 대상’에 표시된 버전을 확인하고 새 이름으로 저장하세요. 원본 파일 기반 버전은 이 버튼을 사용할 수 없습니다. 파일에는 악보만 담기며 반주·녹음·프로젝트 전체 백업은 포함하지 않습니다. 현재 편집본에 과거 버전을 자동 적용하지 않습니다.

조회 내용의 **저장 TAB 보기**로 당시 편집본을 읽기 전용 TAB로 확인할 수 있습니다. **저장된 트랙**을 바꾸면 이 미리보기만 바뀝니다. **저장 TAB 닫기**로 해제하며 현재 연습 악보/재생 위치는 바뀌지 않습니다. 원본 기반 TAB 확장 빌드는 Windows 앱에서 이 버전에 연결된 등록 원본을 읽어 표시합니다. 읽는 중 닫으면 실제 취소 완료까지 기다려주세요. 원본이 없거나 바뀐 경우와 지원 범위를 벗어난 편집본은 표로 확인하세요. 원본 기반 버전의 새 파일 내보내기는 지원하지 않습니다.

### 프로젝트 없이 파일을 잠깐 열기

2026-10-25 끌어놓기 후속 빌드에서는 프로젝트를 열지 않은 카피·연습·연주 화면의 **로컬 파일 끌어놓기** 영역에 악보 또는 WAV/MP3 파일 한 개를 놓을 수 있습니다. 기존 파일 선택 버튼도 사용할 수 있습니다. 악보는8MiB/음원은256MiB 이하이며 폴더·URL·여러 파일은 받지 않습니다. 편집한 악보를 바꾸면 미저장 확인을 먼저 거칩니다. 녹음/채점·파일 처리를 먼저 마쳐주세요. 열린 프로젝트에 파일을 보존할 때는 기존 **프로젝트 악보 선택 / 프로젝트 음원 선택**을 사용합니다. 실제 수용 범위는 [진행 상태](progress/README.md)를 따릅니다.

## 3. 처음에는 반주 없이 짧게 녹음하기

입력 설정의 **디지털 최대값 도달·초과** 수가 늘고 소리가 찌그러지면 인터페이스 입력 GAIN을 낮춰 보세요. 이는 이번 입력 시작 이후 분석된 샘플의 누적값으로, 소리를 작게 해도 과거 수는 남으며 입력을 중단하고 다시 시작하면 초기화됩니다. 실제 왜곡 여부를 확정하는 수치는 아닙니다.

녹음 후 **디지털 최대값(0 dBFS)** 안내가 보이고 소리가 찌그러져 들리면, 앱의 재생 음량 대신 인터페이스의 **입력 GAIN**을 낮추고 새로 녹음해 보세요. 재생 음량은 듣는 크기만 바꾸며 이미 녹음된 왜곡은 복구하지 않습니다. 이 안내는 최대 입력값에 근거하며 실제 왜곡 여부를 확정하는 검사는 아닙니다.

먼저 프로젝트 악보를 저장하고 기타 입력을 시작해 둡니다. 녹음은 연주 실력과 관계없이 아무 줄을 한두 번 튕기는 것으로 확인할 수 있습니다.

1. **환경 설정**의 보정 영역에서 모니터 환경을 확인하고 **보정값 다시 읽기**를 누릅니다. 이전 저장값이 안 나오면 입력 장치/채널·샘플레이트·버퍼·헤드폰/스피커 조건이 달라졌는지 확인합니다.
2. 처음 연결을 확인하는 목적이라면 관측 지연에 **0ms**를 넣고 **수동 보정 저장**할 수 있습니다. 이는 녹음 경로 확인용 임시값이며 타이밍 채점의 정확도를 검증한 값이 아닙니다. 채점 전에는 **반복 연주 보정 시작**으로 측정하거나 확인된 수동값을 사용하세요.
3. **연주**에서 **로컬 반주에 정렬**을 끕니다.
4. **● REC**를 누르고 약5초 동안 아무 줄이나 튕깁니다. 내 소리도 들으려면 모니터를 별도로 켭니다.
5. **STOP · 녹음 저장**을 누릅니다. **READY · …초 · …프레임 · 누락0**이 나오면 저장 상태를 확인한 것입니다. 청취는 다음 단계에서 확인합니다.
6. **녹음 다시 듣기** → **테이크 새로고침** → 방금 테이크를 A로 선택 → **테이크 재생**을 누릅니다. **테이크 재생 음량**과 **음소거**로 듣는 크기를 조절합니다.

소리가 찌그러지거나 peak가 계속1.000에 닿으면 인터페이스의 입력 GAIN을 낮춰 다시 녹음해 보세요. 모니터/다시 듣기 음량을 줄이는 것은 입력 GAIN 조절과 다릅니다.

### 녹음 원본을 다른 폴더에 보관하기

2026-10-25 원본 내보내기 후속 빌드에 추가한 기능입니다. 현재 실행 파일에 버튼이 없으면 해당 기능이 포함된 빌드인지 [진행 상태](progress/README.md)에서 확인하세요.

1. **녹음 다시 듣기**에서 READY 테이크를 A로 고르고 불러오기가 끝날 때까지 기다립니다. 새 입력/REC는 필요 없습니다.
2. **원본 WAV를 새 파일로 내보내기**를 누르고 원하는 폴더에 새 파일명으로 저장합니다. 기존 파일을 덮어쓰지 않습니다.
3. 저장 완료 문구를 확인합니다. 복사본에는 녹음한 기타만 들어 있으며 반주·다시 듣기 음량/음소거·배속/정렬·부분 반복은 적용하지 않습니다.

메모·악보 위치·누락/복구 정보는 WAV에 들어 있지 않습니다. 프로젝트 전체가 필요하면 [로컬 백업](19-BACKUP-AND-RECOVERY.md)을 사용하세요. 복구본을 내보내도 빠진 소리가 되살아나지는 않습니다.

### REC가 회색일 때

버튼 아래의 이유 문구부터 확인합니다. 흔한 조건은 **프로젝트 악보 미저장**, **입력 미시작**, **현재 입력/모니터 환경의 보정값 없음**입니다. 다른 입력으로 바꾸면 이전 보정값이 바로 적용되지 않을 수 있습니다. 반주 정렬을 켠 상태에서는 로컬 음원·반복 해제·추가 레이어가 있다면 **오버더빙 믹스 준비**도 필요합니다.

## 4. 반주에 맞춰 연습/녹음하기

- 악보와 로컬 반주를 프로젝트에 저장합니다. 악보 커서와 반주의 위치가 맞지 않으면 싱크를 먼저 맞춥니다.
- 처음에는 느린 배속으로 재생합니다. 재생 버튼 뒤3초 준비 표시가 나오며 **준비 취소**로 중단할 수 있습니다.
- 녹음할 때는 반복을 끄고 **로컬 반주에 정렬**을 켭니다. 필요한 믹스를 준비한 뒤 정지 상태에서 **● REC**를 누르면3초 준비 후 반주와 녹음이 시작됩니다. 재생 중 REC는 현재 위치부터 시작합니다.
- 새 테이크에는 선택한 기타 입력만 저장합니다. 반주와 섞인 파일이 필요할 때는 별도 로컬 믹스/WAV 출력 기능을 사용합니다.
- **채점 시작**은 별도 동작입니다. 현재 점수는 깨끗한 단음용입니다. 화음·주법·저신뢰 구간은 감점 제외될 수 있어 악보8음이 모두 콤보8로 이어지는 것은 아닙니다.

## 문제가 생겼을 때

| 상황 | 먼저 확인할 것 |
|---|---|
| 장치가 안 보임 | 연결 후 입력 중단 → 입력 장치 새로고침 → 사용할 장치/채널 선택 |
| 튜너만 움직이고 소리 없음 | 모니터 기본 꺼짐, 모니터 출력 장치와 헤드폰 연결 위치 |
